# KK-FRONTEND v0.3.0 — Design Picker + Source Generator

## Added
- Reference design entity catalog for Section, Component, Text and Animation selections.
- Visual picker API/UI over scanned reference screenshots.
- Evidence inspector with computed style, DOMRect and animation timing/keyframes.
- Selection persistence as `design-selection.json`.
- Target-aware source reconstruction generator for React/Next, Vue/Nuxt, Svelte and HTML/CSS targets.
- Generated `reference-design-selection.css`, framework component and `generation.json`.
- Target source-file hints from the existing source audit.
- Dedicated synthetic design-picker/source-generator test.

## Source-code semantics
Generated code is an equivalent implementation reconstructed from VERIFIED runtime evidence. KK-FRONTEND does not claim that it is the reference site's proprietary original source code.
