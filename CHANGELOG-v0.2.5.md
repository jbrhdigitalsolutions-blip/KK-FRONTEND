# KK-FRONTEND v0.2.5 — FLEX EXECUTION + UX

- Git is no longer mandatory for local project execution.
- Clean Git target -> isolated Git worktree.
- Non-Git or dirty-Git local target -> isolated safe copy; original remains untouched.
- Verified safe-copy changes can be explicitly applied back with automatic pre-apply backup and rollback on failed verification.
- Live/localhost URL-only targets support Scan, Compare, Plan and Coding Handoff without producing a misleading Git failure.
- Missing coding agent no longer needs to become a failed execution job: Generate Coding Handoff remains available.
- Added execution capability detection and mode messaging.
- Added source-aware Target UX, workflow stepper, clearer notices, responsive controls and mobile layouts.
- Keeps v0.2.4 Select all / Select visible / Same Category / Same Subcategory / Same Route selection features.
