# KK-FRONTEND v0.8.0 — Project-Aware Exact Design Builder

## Why this release exists

The v0.6/v0.7 Build Preview could preserve broad evidence and responsive anchors, but Accurate mode still produced generic semantic templates. A strong reference hero could therefore become generic Brand / Get started / Image blocks.

v0.8.0 moves project understanding before source generation and reconstructs measured child elements rather than inventing generic components.

## Project Fit
- Existing / New project modes.
- Project name and target route.
- Framework auto-detection with manual fallback.
- Package-manager detection / preference.
- Windows / macOS targets.
- Content strategy and final text fields.
- Asset strategy and explicit asset-path mapping.
- Optional project constraints.
- Project-folder upload and key-file upload.
- Current DESIGN.md / package / route / component / styling / token file analysis.
- Dynamic required/recommended items.
- Separate complete-intake vs exact-ready status.
- Explicit Prototype fallback.

## Project source intelligence
- Detects Next.js, React/Vite, React, Vue, Svelte and HTML evidence.
- Detects pnpm/npm/yarn/bun.
- Detects TypeScript vs JavaScript.
- Detects Tailwind, CSS Modules, Sass, styled-components, Emotion and plain CSS.
- Detects source, component and route roots.
- Extracts reusable project text snippets and media references.
- Rejects .env / credentials / private-key style uploads.
- Web payload analysis is text-only and bounded.

## Accurate reconstruction
- Uses measured selected-root geometry.
- Reconstructs semantic child layers instead of generic hero/card templates.
- Carries Desktop / Tablet / Mobile positions.
- Carries observed text/background/font/border/radius/shadow/opacity styles.
- Reuses project content or supplied final content.
- Reuses existing project asset references or supplied project/public asset paths.
- Reports measured-layer count and responsive evidence match.

## Generated package
- Existing projects: isolated kk-generated integration source.
- New projects: runnable Next.js, React/Vite or HTML/Vite trees.
- Includes reference DESIGN.md, fit/build manifests, dependency plan, integration guide, PC requirements and setup/run scripts for Windows and macOS.
- Includes combined setup-and-run scripts.

## Verification
- Project-aware tests cover stack detection, exact readiness, media/content requirements, sensitive-file rejection, responsive measured reconstruction, runnable new-project output and ZIP creation.
