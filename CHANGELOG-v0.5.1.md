# KK-FRONTEND v0.5.1 — Visual Design Explorer

## Design-region intelligence
- Expanded detection beyond generic sections/animations to semantic structure, controls, content, media and motion families.
- Added Hero, Card, Grid, Button, Input, Search, Typography, Image, Video, Carousel, Gallery, Tabs, Badge, Icon, Logo, Avatar and related classifications.
- Semantic identity always wins over generic motion classification.
- Inspection response now includes family/type facets for fast filtering.

## No-code selection workflow
- Added design-family filters and search.
- Added Select filtered.
- Added Quick select presets: Essential design, Structure, Typography, Controls, Media and Motion.
- Added balanced Essential design selection.
- Added explicit 30-region custom-selection limit.
- Preserves user-selected label, kind and family metadata into generated evidence.
- Direct visual overlay selection remains available.

## UI
- Rebuilt the Reference → DESIGN.md page as a slim glassy Design Explorer.
- Reduced visual density and selector noise.
- Added semantic badges, region dimensions and interaction/motion/sticky signals.
- Improved desktop, tablet and mobile responsiveness.

## Source-aware foundation
- Includes v0.5.0 design-contract, source-intelligence, component-map, migration-guard and post-change visual verification work.
- Users can define/export a desired reference design without configuring a coding agent.
- Source mutation remains separately safety-gated.

## Reliability
- Fixed Windows file-URL path conversion in flex-execution tests.
- Keeps local and Vercel public copies byte-identical.
