# KK-FRONTEND v0.9.0 — Multi-Source Project Intelligence + Visual Certification

## Problem proven by the v0.8 generated project
- A real reference page was reduced to a handful of overlapping generic regions.
- Generated output contained generic Typography/Image/placeholder sections instead of the reference hierarchy.
- Nested frontend package roots such as `web/` were not retained in generated target paths.
- Project Fit could report Accurate-ready with insufficient design/source evidence.
- Split preview clipped a true 1440px iframe instead of fitting it cleanly.
- There was no objective rendered visual-difference measurement.

## Reference extraction
- Preserve parentSelector, ancestor selectors, child index, depth, text and media attributes.
- Retain layout/styled containers, not only semantic elements.
- Raise compact representative evidence cap to 300 nodes per viewport.

## Project intelligence
- Add GitHub repository source scanning with optional ephemeral token.
- Add live project website content/runtime scan.
- Merge GitHub + website + local evidence; local files win path conflicts.
- Prioritize frontend/design files for large local folders.
- Strip browser-added folder wrapper from webkitdirectory uploads.
- Detect frontend package root in monorepos.
- Detect nested Next.js routes relative to package root.
- Extract source components, import dependencies, content strings, asset references and links.
- Tighten Accurate readiness for existing projects.

## Accurate renderer
- Build a parent/child reference tree from browser evidence.
- Render exact hierarchy with measured style evidence at desktop/tablet/mobile.
- Substitute target-owned content and assets.
- Do not automatically reuse third-party reference text or CSS image URLs.
- Preserve original target source in exported ZIP when available.

## Viewer
- Add Overlay and Diff modes.
- Add strict pixel and structural-edge similarity measurements.
- Add Fit and 100% pixel preview modes.
- Keep the iframe at its real requested viewport while fitting the visual presentation into the available pane.

## Safety
- SSRF protections remain active for website/reference scans.
- GitHub tokens are never persisted or returned.
- Existing-project apply scripts remain backup-first.
- Package installation respects detected monorepo package root.
