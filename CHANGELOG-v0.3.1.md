# KK-FRONTEND v0.3.1 — Professional UX

## UX upgrade
- Rebuilt the WebApp into a guided professional workspace with sticky workflow navigation.
- Promoted Design Picker to the primary visual workspace.
- Added clearer session state, source/target setup cards, progress telemetry and implementation safety states.
- Added responsive desktop/tablet/mobile layouts with dense but readable spacing.
- Added accessibility-focused focus states and reduced-motion support.
- Added layer legend, viewport chrome, evidence inspector, selection dock and stronger generated-source presentation.
- Preserved all v0.3.0 functional IDs and workflows.

## Usability fixes
- Comparison category filter now preserves the user's selected category across rerenders.
- Resumed sessions automatically attempt to restore the Reference Design Picker catalog.
- New sessions reset stale design-picker state.
- Workflow rail highlights the active area as the user moves through the application.
