# KK-FRONTEND v0.2.4 — GROUP SELECTION

Compare selection upgrades:
- Select all differences at once.
- Select all currently visible/filtered differences.
- Select all rows matching the currently selected Category.
- Select all rows matching the currently selected Subcategory.
- Select all rows matching the currently selected Route.
- Header checkbox selects/clears the entire comparison and shows indeterminate state.
- Double-click Route, Category or Subcategory cells to select that complete group.
- Clear removes all selections.
